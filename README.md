# hardware_exe
Windows and Linux folders with BM, I-ODM, I-OSM, AEM and Nodes softwares

CODE = BM, ISM, OSM, IDM, ODM, AEM, RDN, SDN, SVN, RDN
VERISON should be like this x.x.x

To build the exe: powershell -NoProfile -ExecutionPolicy Bypass -File .\build_windows.ps1 -Code <CODE> -Version <VERSION>
